# 📚 Student Study Planner and Task Management System

## 📌 About
A web-based application that helps students organize study tasks, manage deadlines, track study sessions, and monitor their progress.

## ✨ Features
- Add and manage study tasks.
- Set task deadlines.
- Mark tasks as completed.
- Record study sessions.
- View study progress on a dashboard.

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub

## ⚙️ How to Run

1. Install dependencies:
   `pip install -r requirements.txt`
2. Set up the MySQL database using `database/schema.sql`.
3. Start the application:
   `python backend/app.py`
4. Open `http://127.0.0.1:5000/` in your browser.
